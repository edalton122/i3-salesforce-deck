Technical Architecture

Five layers. One platform.
Built for security and scale.

Designed for a DoD contractor's Infosec vetting requirements. Click any layer to expand the detail.

1Source Systems
Deltek ATS SharePoint + Others

Deltek is i3's ERP and system of record for contract financials and labor. The applicant tracking system holds hire, clearance, and skills data. SharePoint holds program documents and assignment records. Each system keeps running unchanged — Informatica reads from all of them. Nothing about these systems changes on Phase 1 go-live.

2Data Integration
Informatica IDMC — Owned Today Live Pipelines

The Informatica Data Integration IPUs i3 purchased in January 2026 ($66,758.40) run the extract, transform, and load pipelines that pull data from the source systems and make it available for MDM and downstream consumers. Ron Givens configured these pipelines. Phase 1 does not replace or reconfigure these pipelines — MDM sits on top of the data they already produce.

3MDM + Quality
Match & Merge Survivorship Quality Rules

Informatica MDM receives the integrated data from Layer 2, runs a configurable match engine to identify duplicates and related entities, applies survivorship rules to decide which field value becomes the master, and writes a single trusted record to the golden record store. Data Quality rules run in parallel — flagging expired clearances, missing skills, incomplete contract fields — so the issues reach a steward rather than a downstream consumer. This is the core of the $150K MDM line item.

4Governance
Privacy Tags Data Lineage Policy Engine Infosec Audit

Informatica Data Governance + Privacy IPUs apply field-level access policies to the golden record — so clearance data, SSNs, and other sensitive fields are masked or restricted by role. Complete data lineage records where every field came from and every transformation applied, which satisfies IT and Infosec vendor-vetting requirements (noted as a friction point in the Informatica close plan). This is the $25K Governance + Privacy line item. It also provides the compliance traceability needed as i3 works toward CMMC and DFARS requirements.

5Activation
Tableau Data Cloud Agentforce Slack

These are roadmap items only — not in Phase 1 scope. Once a trusted data layer exists, Tableau dashboards draw from it without manual pre-aggregation. Data Cloud can activate employee and contract records for real-time program management. Agentforce can apply predictive staffing and capture intelligence that i3 currently delivers for its DoD customers to i3's own operations. Slack would serve as the collaborative command center — alerting stewards, routing approvals, and surfacing insights where i3's teams already work. Each of these was suggested by the i3 leadership website, not confirmed in any discovery session.

i3's Infosec and vendor-onboarding requirements were cited as friction in the 2026 Informatica close. This architecture is designed to satisfy those requirements: field-level privacy controls, complete data lineage, role-based access, and a separation of concerns between integration, mastering, and governance that maps to a standard security review framework.
